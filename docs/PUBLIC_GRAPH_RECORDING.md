# 公開グラフ記録機能

RadioPulseViewer の「グラフ値を記録」は、Yahoo! JAPANリアルタイム検索などの公開グラフを参照し、利用者が画面で確認した件数だけをCSVへ保存する機能です。

## 方針

- WebページのHTMLやDOMを解析しません。
- 通信レスポンスの傍受や内部JSONの取得を行いません。
- グラフのツールチップを自動操作しません。
- CAPTCHA、アクセス制限、認証、レート制限を回避しません。
- 投稿本文、投稿者、プロフィール、画像、動画を取得しません。
- APIの認証情報は必要ありません。

この方式は自動取得ではありません。公開ページに表示された値を利用者が確認し、RadioPulseViewerへ入力して記録します。

## 使い方

1. 週間番組表から番組を選択します。
2. 右側の検索語を確認します。
3. 「グラフ値を記録」を開きます。
4. 表示期間を選択し、「参照ページを開く」を押します。
5. 公開グラフ上にマウスポインタを合わせ、表示ラベルと件数を確認します。
6. 1行につき `表示ラベル, 件数` の形式で入力します。
7. 「プレビュー」で内容を確認し、「CSVへ保存」を押します。

入力例:

```text
8/3 18:00, 125
8/3 19:00, 842
8/3 20:00, 391
```

カンマの代わりにタブ、読点、半角スペースも使用できます。件数には3桁区切りのカンマや末尾の「件」を含められます。

## 合計だけを記録する場合

時系列データを入力せず、「合計件数」だけを入力して保存できます。

時系列データを入力し、合計件数を空欄にした場合は、各点の合計を保存します。公開グラフ全体の合計と各点の合計が異なる場合は、画面に表示された合計値を明示的に入力してください。

## CSV

保存先:

```text
%LOCALAPPDATA%\RadioPulseViewer\PublicGraphRecords\public-graph-records.csv
```

保存項目:

- 記録日時
- データ源
- 検索語
- 表示期間
- 合計件数
- データ点の順番
- グラフ上の表示ラベル
- 各データ点の件数
- メモ

CSVへ保存する文字列は、表計算ソフトで数式として解釈される文字から始まる場合に無害化します。

## 数値の扱い

保存される値は、記録時点に公開ページへ表示されていた数値を利用者が転記したものです。RadioPulseViewerが外部サービスから自動取得した値ではありません。

公開ページ側の集計対象、除外処理、更新時刻、表示仕様が変わる可能性があります。分析資料ではデータ源、表示期間、記録日時を併記してください。

公式X APIを利用できる環境では、別機能の「公式X投稿数」でAPI集計値を取得できます。両者は取得元と集計条件が異なるため、同一の指標として混在させないでください。
